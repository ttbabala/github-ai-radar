# Trend taxonomy

The editable source of matching terms is `config/radar.yaml`.

Domains supported: Frontier Model, Open Model, Small Model, MoE, Fine-tuning, Multimodal, Vision, Speech, Video, Robotics, AI Coding, Agent, Agent Skills, Agent Memory, Agent Runtime, Agent Sandbox, Agent Security, Context Engineering, RAG, Knowledge System, MCP, Multi-Agent, Agent Organization, Computer Use, AI Search, AI Research, Local AI, Edge AI, Enterprise AI, AI Infrastructure, AI Evaluation, AI Governance, AI Safety.

Technology layers: L1 Model Layer; L2 Capability Layer; L3 Agent Layer; L4 Runtime Layer; L5 Orchestration Layer; L6 Application Layer; L7 Enterprise / AI Operating System Layer.

Matches are based on repository name, description, topics and a bounded README excerpt. Multiple domains/layers are allowed. A default classification is a fallback and should be interpreted cautiously.
